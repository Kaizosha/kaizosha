01 / Native by design

One globe.
Zero web runtime.

SekaiKit owns its shaders, geographic data, controls, interaction model, and resources. Host apps import one package—without JavaScript, WebView, WebGL, MapKit, network access, or location permission.

29,821

Full-density points

Every country, continent, and land source remains crisp at maximum density.

177

Countries included

Bundled, offline geographic data with particle and boundary rendering modes.

60 FPS

Metal performance

Particles, boundaries, markers, and routes share a single transparent render pass.
